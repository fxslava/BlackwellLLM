Model & inference

Capture & timing

While you type, the captured area shows dimmed in the overlay. Pause for the idle delay to translate it; the commit shortcut replaces it with the translation.

Memory budget — prefix cache

Cold translation-context pages demote VRAM → pinned RAM → disk instead of being recomputed. Changing these requires an app restart (engine rebuild).

Translation directions

The source language is auto-detected; each pair only sets the target. Every pair gets a global Alt+<N> force hotkey (Alt+1 = first pair) that pins that direction. Adding/removing pairs takes effect on the next app start (the engine compiles one prompt-cache branch per pair).
